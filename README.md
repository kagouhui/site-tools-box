# Site Tools Box

[![Website](https://img.shields.io/badge/Website-sitetoolsbox.com-blue)](https://sitetoolsbox.com/)

**Site Tools Box** is a free online toolbox for webmasters, developers, and digital marketers. All tools are completely free and require no login.

### 🌟 All Available Online Tools

**🌐 Network & Domain Tools**
- [WHOIS Lookup](https://sitetoolsbox.com/tool.php?slug=whois) - Check domain ownership and registration details.
- [DNS Lookup](https://sitetoolsbox.com/tool.php?slug=dns) - Query A, CNAME, MX, and TXT records.
- [IP Lookup](https://sitetoolsbox.com/tool.php?slug=ip) - Find the location and ISP of any IP address.
- [Domain Availability](https://sitetoolsbox.com/tool.php?slug=domain-check) - Check if a domain is available for registration.
- [Domain Query](https://sitetoolsbox.com/tool.php?slug=domain_query) - Advanced domain research and query tools.
- [HTTP Status Checker](https://sitetoolsbox.com/tool.php?slug=http_status) - Check HTTP status code and response time.
- [Bulk HTTP Status](https://sitetoolsbox.com/tool.php?slug=http_status_batch) - Check up to 50 URLs at once.
- [Ping Test](https://sitetoolsbox.com/tool.php?slug=ping) - Test network latency and reachability.
- [Port Scanner](https://sitetoolsbox.com/tool.php?slug=port_scan) - Check which ports are open on a host.
- [Dead Link Checker](https://sitetoolsbox.com/tool.php?slug=dead_link) - Scan a page for broken links.

**💻 Developer Utilities**
- [JSON Formatter](https://sitetoolsbox.com/tool.php?slug=json_format) - Format, minify, and validate JSON online.
- [Timestamp Converter](https://sitetoolsbox.com/tool.php?slug=timestamp) - Convert Unix timestamps to dates and back.
- [QR Code Generator](https://sitetoolsbox.com/tool.php?slug=qrcode) - Generate high-quality QR codes.
- [URL Shortener](https://sitetoolsbox.com/tool.php?slug=short_url) - Turn long URLs into short links.
- [Badge Maker](https://sitetoolsbox.com/tool.php?slug=badge-maker) - Create custom badges for your projects.

**🛒 E-commerce & Business**
- [Profit Calculator](https://sitetoolsbox.com/tool.php?slug=ecommerce-profit) - Calculate profit, margin, ROI, and break-even.
- [Shipping Calculator](https://sitetoolsbox.com/tool.php?slug=shipping-calculator) - Estimate shipping for USPS, UPS, FedEx, DHL.
- [Discount Calculator](https://sitetoolsbox.com/tool.php?slug=discount_calculator) - Calculate sale price and savings.
- [ROI Calculator](https://sitetoolsbox.com/tool.php?slug=roi-calculator) - Measure ROAS, ROI, and net profit for ad campaigns.

**📈 SEO & Marketing**
- [Meta Tag Extractor](https://sitetoolsbox.com/tool.php?slug=tdk) - Extract title, description, and keywords.
- [UTM Link Builder](https://sitetoolsbox.com/tool.php?slug=utm-link-builder) - Generate trackable links for campaigns.
- [UTM Stats Dashboard](https://sitetoolsbox.com/tool.php?slug=utm-stats-dashboard) - Analyze your UTM campaign performance.

**🤖 AI Tools**
- [AI Text Humanizer](https://sitetoolsbox.com/tool.php?slug=ai-text-humanizer) - Make AI-generated text sound more natural.
